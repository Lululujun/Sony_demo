# 索尼产品动态分配 Agent · 客户演示脚本

建议时长 10–12 分钟。页面顺序与 RFP 重构版方案的关键章节一致：智能分层 → 分货引擎 → 方案预演 → 比例与特殊物料 → 动销库存 → 后台管理。

## 演示前准备

1. 使用 Chrome 或 Edge，推荐 1920×1080、100% 缩放；1280×720 也可完整操作。
2. 打开 `/?demo=1`，选择“PPT 示意场景 / WH-1000XM6”。
3. 说明当前为固定演示数据，页面中的计算、轨迹、校验和 CSV 均为真实前端逻辑。
4. 指出三类输入来源：MIA 月度目标、SAP 订单/库存/货款、SSP 历史 PSI。

## 1. 智能分层

对应方案 P9，建议 2 分钟。

1. 进入“智能分层”，先选择 **P1 货源充足**。
2. 指出组织树的六级结构：总部 → 渠道 → 子渠道 → 大区 → 分公司 → 经销商。
3. 解释满足度：

   ```text
   满足度 = 当前层获得的可分配量 ÷ 当前层有效净需求
   ```

4. P1 中总部满足度达到总部阈值，因此停靠在总部，下游灰显并提示可直接下单。
5. 切换 **P2 货源偏紧**。渠道 A 满足度达到渠道阈值并停靠；渠道 B、C 未达阈值，继续向下分配。
6. 调整一个 PIC 停靠阈值，观察停靠层级和页面底部 Agent 决策轨迹同步变化；点击任一轨迹步骤，可让组织树定位并高亮对应节点。

讲解重点：Agent 不是固定下沉到经销商，而是选择“当前供需条件下最高且安全的分配层”；每一次停靠或下沉都有满足度、阈值和 PA Plan Ratio 依据。

## 2. 分货工作台

对应方案 P10–P13，建议 3 分钟。

1. 进入“分货工作台”，指出 SKU 旁的三系统来源标签：
   - MIA：月度目标；
   - SAP：订单、库存、货款；
   - SSP：历史 PSI。
2. 查看横向轨道：蓝色为公平层，绿色为效率层；竖线分别表示需求与资金上限。
3. 点击“重算并回放”，观察中原电子-B 在 50 台触达资金上限，未使用份额继续分给 A、C。
4. 最终确认 A/B/C 为 108/50/52，合计 210 台，整数与总量校验通过。
5. 展开 A 的分配明细，展示逐步 trace、每步增量和最终守恒。
6. 指出大客户徽标和“本周上限”；大客户可豁免 Wkly Ratio，但仍不能突破货款余额。
7. 打开 Skip 示例 SKU，说明命中后自动求解被停用，并转 SSP 人工分配。
8. 点击“调用 SAP 产品分配 RFC 回写”，说明当前 Demo 只模拟执行结果，正式环境由后端代理调用。

讲解重点：公平层保障覆盖，效率层结合动销和库存健康做倾斜；资金额度、Wkly Ratio、总量和整数性是显式约束，不由解释文案决定。

## 3. 方案对比

对应方案 P14，建议 1 分钟。

1. 进入“方案对比”，查看偏公平、均衡、偏效率三张方案卡。
2. 选择一个经销商，观察三套方案下分配量和满足率的变化。
3. 对比分货集中度、预计缺货率、覆盖经销商和周转指标。
4. 点击“采用此方案”，返回工作台确认当前求解参数与轨道同步更新。

讲解重点：三套方案使用相同数据和硬约束，只改变业务取向；方案差异是可计算、可比较的，不是三套静态截图。

## 4. 比例与特殊物料

对应方案 P17 与 P20，建议 2 分钟。

1. 进入“比例与特殊物料”，选择一个经销商。
2. 指出 PA Plan Ratio 的三个分项：
   - 供需态势；
   - 经销商经营状态；
   - 策略配置。
3. 调整三项权重，观察分项得分、最终 ratio 和计算轨迹实时变化。
4. 查看 Wkly Ratio：

   ```text
   普通客户本周上限 = floor（月度目标 × Wkly Ratio）
   ```

5. 打开“大客户”标识，指出周上限变为计划参考，但资金上限仍生效；`kBig` 只影响计划倾向。
6. 展示“直营优先 + Buffer”的三步顺序：先满足直营，再从余额预留 Buffer，最后形成其他渠道池。
7. 在多色区域查看 P1/P2：按过去 3 个月 DO 比例拆分，单色可以超过自身目标，但型号合计不得超过整体目标。
8. 在 Skip 清单中添加或移除物料，观察当前 SKU 是否允许自动分配。

讲解重点：比例不是一个无法解释的黑盒分数。每个分项、权重、豁免和硬上限都能分别查看，特殊物料也有独立的总量校验。

## 5. 周转与校准

对应方案 P19，建议 1.5 分钟。

1. 进入“周转与校准”，选择一个经销商。
2. 说明主口径来自 SSP 过去 12 个月 PSI：

   ```text
   sellout 消化周转周期 = 当前 PSI 库存 ÷ 对应时期周均 sellout
   ```

3. 切换“平销期 / 大促期”，观察两组周均 sellout 和周转周期变化。
4. 查看 14 天库存估算与置信区间：距离周一真值越远，区间越宽；真值到达后重新收窄。
5. 指出右侧交叉校验：

   ```text
   估算去货量 ≈ 期初库存 + 本期分货 − 期末库存
   ```

6. 点击“至下周一”并执行校准，说明小偏差用于微调参数，大偏差会降低库存可信度。

讲解重点：SSP PSI 是周转主口径；库存流量法是交叉校验。系统同时展示平销与大促差异，并明确表达估算不确定性。

## 6. 后台管理与 AI 诊断

对应方案 P18 与 P24，建议 2 分钟。

1. 进入“后台管理”，依次指出八项能力：
   - Wkly Ratio 配置；
   - 大客户标识与 `kBig`；
   - Skip 免分配清单；
   - 同型号多色规则；
   - 提示词调整；
   - PA Plan Ratio 权重；
   - 分配记录查询与 CSV；
   - 用户权限矩阵。
2. 修改一项配置，查看右侧立即出现“操作人、旧值 → 新值、时间、版本号”。
3. 点击“回滚到上一版”，确认配置恢复，同时回滚动作本身也被记录。
4. 导出当前分配记录 CSV，说明文件使用 UTF-8 BOM，可直接用 Excel 打开。
5. 查看三类诊断：
   - 数据类：缺数、净需求异常、采集超时；
   - 结果类：满足度骤降、集中度过高、经销商分配为零；
   - 执行类：RFC 失败、任务超时、重试耗尽。
6. 展开参数快照和证据，点击“下钻到轨迹”返回对应求解页面。

讲解重点：提示词只影响解释，不影响分配计算；配置可版本化、可回滚；诊断由当前数据和结果真实计算，并能回到证据链。

## 收尾

回到顶部，选择“到货触发”或“定时批量”，点击“触发分货”。用一句话总结：

> Agent 将 MIA、SAP、SSP 的业务数据转成可审计决策，先判断分配层级，再计算比例与硬约束，最后输出可回写、可诊断、可追溯的分货结果。
