# 客户演示脚本（建议 8 分钟）

## 1. 分货工作台

1. 打开“PPT 示意场景”，先看横向满足率轨道的完成态。
2. 指出每行同时显示需求、额度、公平量、效率量、最终量与满足率。
3. 点击“重算并回放”，观察 B 在 50 台触达额度上限，剩余货量继续流向 A、C。
4. 最终确认 A/B/C 为 108/50/52，总分配 210 台。
5. 展开 A 的分配轨迹，展示每一步增量与守恒校验。
6. 拖动公平预算 β 或修改额度，观察结果自动刷新。

讲解重点：资金额度是硬约束；公平层先形成基础满足率，效率层再按动销与库存健康分配剩余货量。

## 2. 方案对比

1. 对比偏公平、均衡、偏效率三张方案卡。
2. 在斜率图中选择 A，观察其分配量 103 → 108 → 113 的变化。
3. 采用偏效率方案，系统自动返回分货工作台并更新轨道。

讲解重点：三套方案使用同一个算法和硬约束，仅改变业务取向参数。

## 3. 锁单看板

1. 从工作台点击“回写 SAP”。
2. 对 B 发起锁单，实时余额仅覆盖 32/50 台，18 台立即回流。
3. 对软锁卡确认支付，或点击“模拟超时”。
4. 查看右侧额度拦截记录和回流数量，再切回工作台确认回流指标已更新。

讲解重点：额度表示“能锁多少”，并非简单的是/否判断；超时释放会影响履约记录。

## 4. 周转与校准

1. 展示 14 天库存估算线和逐日张开的置信区间。
2. 说明上界用于防积压的补货判断，下界用于保供判断。
3. 快进到下周一，打开校准弹窗。
4. 对比估算与真值：5 家微调动销，C 偏差超阈值后标记为不可信。
5. 应用后返回工作台，C 显示“仅保底”。

讲解重点：系统明确表达不确定性；异常数据不会被删除，而是退出效率倾斜并保留公平兜底。
